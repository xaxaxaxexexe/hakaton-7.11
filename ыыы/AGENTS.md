# Правила работы над SEKTOR

Прочитай README.md, docs/criteria.md и docs/api.md.

- frontend принадлежит Makhkets, backend — jasperBLCK; main содержит совместимую версию.
- Фронтендер меняет apps/web. Бэкендер меняет apps/api, docs/platega.md, docs/deployment.md.
- contracts/openapi.json — общий договор. Имена полей, коды ошибок и система координат одинаковы в обоих приложениях. Изменение контракта согласуй с напарником и обнови обе стороны.
- Сначала работающий путь: стадион → матч → сектор → место → 3D → оплата → билет. Затем дополнительные возможности.
- Не подменяй подтверждение платежа редиректом, query-параметром, кликом пользователя или ответом мока.
- Цены и доступность определяет сервер. Не передавай сумму от клиента как источник истины.
- Никогда не коммить .env, ключи, тела запросов с секретами, БД с покупателями. Примеры содержат только пустые значения.
- Не печатай секреты в терминал, не копируй их в промпт в репозитории, не добавляй их в VITE_*.
- Не меняй callback URL существующего мерчанта без проверки, какие другие проекты им пользуются.
- Не выполняй реальные списания или возвраты в автоматических тестах. Проверка авторизации уже выполнена read-only; см. docs/platega-check.json.
- Для 3D используй одну геометрию с 2D. Любое место должно менять положение камеры.
- Каждый законченный этап — небольшой commit и PR в main. Не force-push и не переписывай чужую историю.
- Перед PR: соответствующие проверки, список закрытых критериев, способ воспроизведения. Не заявляй выполненными ещё не работающие функции.

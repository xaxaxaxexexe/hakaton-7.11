# Критерии кейса

Источник: [кейс «Билет с видом на поле»](source/hackathon-brief.pdf). Баллы выставляет жюри; здесь указано, где это посмотреть в проекте.

| Критерий | Максимум | Где смотреть |
| --- | ---: | --- |
| Покупка билета | 5 | Стадион → матч → сектор → место → оплата → QR-билет. Цена зависит от ряда и сектора, купленное место занято на схеме и в 3D |
| Полноценность продукта | 5 | Стадионы, матчи и цены в данных, заказы в SQLite, билет сохраняется после перезапуска |
| 3D-вид с места | 5 | «Сесть и посмотреть» для любого места, кнопки «Ниже» и «Выше», сравнение двух мест, возврат к схеме |
| Качество продукта и UX | 3 | Единый стиль, адаптивная вёрстка, обработка ошибок и занятых мест |
| Презентация проекта | 3 | Живая покупка в демо-режиме |
| Код и архитектура | 2 | `docs/architecture.md`, новый стадион добавляется через `scripts/generate_stadium_fixtures.py` |
| Размещение на хостинге | 1 | `docs/deployment.md`. Новая версия не размещена |
| Звук с места | +2 | Синтез шума трибун в браузере: у фан-сектора громче, наверху тише |
| Интеграции | +3 | Платёжный адаптер Platega СБП (в демо-режиме отключён) |
| Своя идея | +2 | Подбор места, паспорт места, места рядом, чат матча, живое обновление занятых мест |

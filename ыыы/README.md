# SEKTOR — билет с видом на поле

Сервис покупки билетов на спорт: выбрать стадион и матч, сесть на место в 3D, посмотреть на поле, послушать трибуну, оформить заказ и получить QR-билет.

Frontend подключён к FastAPI и SQLite. В каталоге три вымышленных стадиона, 12 матчей и 15 секторов. Клубы, стадионы и матчи выдуманы, билеты не дают прохода на реальные мероприятия.

> **Перед включением `PAYMENT_PROVIDER=platega`:** этот режим списывает настоящие деньги, а стадионы и матчи в каталоге вымышленные. Для показа используйте `mock`. Реальную оплату включайте только с настоящими мероприятиями организатора.

## Что можно показать

- Выбор стадиона, расписание матчей и поиск по командам и турнирам.
- Схема стадиона с секторами и схема сектора: поле сверху, ряды 1–9, ложи в верхнем ряду. Цена зависит от ряда и сектора.
- 3D-вид с любого места: игроки, мяч, чаша трибун и болельщики. Купленные места появляются в 3D как болельщики.
- Сравнение двух мест, подбор места по предпочтению и пересадка выше и ниже по трибуне.
- Звук с места, синтезируемый Web Audio: у фан-сектора громче, на верхней отметке тише.
- Чат матча между посетителями: SSE, реакции и эмоуты. История хранится в памяти одного процесса.
- Серверная цена, атомарная бронь, идемпотентность, приватный доступ к заказу, QR и восстановление после рестарта.

## Локальный запуск

Требуются Python 3.12+ и Node.js 22+. Из корня клонированного репозитория:

```sh
cd apps/api
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
PAYMENT_PROVIDER=mock DATABASE_PATH=./data/zal-integration.db \
PUBLIC_APP_URL=http://localhost:5173 PUBLIC_API_URL=http://127.0.0.1:8000 \
ENABLE_EXTERNAL_MEDIA_NETWORK=0 ENABLE_BACKGROUND_RECONCILER=1 \
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

Во втором терминале из корня:

```sh
cd apps/web
npm ci
npm run dev
```

Открыть **http://localhost:5173**. API и постоянная БД настоящие, платёжный провайдер в этой команде — sandbox без списания денег. `scripts/mock_api.py` остаётся отдельным инструментом разработки; одновременно с API на порту 8000 его не запускать.

Приватный `apps/api/.env` не передаётся при клонировании. При необходимости создайте его из `.env.example` только при отсутствии существующего файла. Не перезаписывайте заполненный `.env`, не передавайте ключи во frontend и не добавляйте секреты в Git.

## Как добавить стадион

Опишите стадион в `STADIUMS` в `scripts/generate_stadium_fixtures.py` (секторы, ряды, цены, матчи) и запустите скрипт: он пересоберёт `contracts/fixtures`. Код приложения менять не нужно.

Имена сущностей в API и базе: `cinema` — стадион, `movie` — матч, `hall` — сектор, `session` — матч в конкретном секторе, `screen` — поле.

## Проверки

```sh
python3 scripts/check_contract.py
python3 scripts/smoke_mock.py
cd apps/api
.venv/bin/python -m unittest discover -s tests -v
```

Сборка frontend: `cd apps/web && npm run build`. CI запускает проверки контракта, backend-тесты и сборку. Backend-тесты покрывают каталог и доступ, SQLite/restart, гонки, повтор платежа/callback, неоднозначные ответы, суммы, спор и возврат и чат. Платёжные тесты используют фейкового провайдера и не списывают деньги.

## Цены

Тарифы задаются для каждого стадиона и сектора в `scripts/generate_stadium_fixtures.py`. Например, в центральном секторе Арены Невской: **700 / 1 200 / 3 500 ₽**. Настройка `DEMO_CHECKOUT_MINOR` меняет сумму оформления на сервере; значение `0` оставляет цену каталога.

Чат закреплён справа на широком экране, сворачивается и запоминает выбор пользователя. На телефоне открывается отдельной панелью над нижней кнопкой покупки.

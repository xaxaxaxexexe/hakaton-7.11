# ZAL — фронтенд

React + TypeScript + Vite, Three.js, Web Audio и Motion. Интерфейс получает стадионы, матчи, цены, геометрию и доступность по API. Ключей Platega в клиенте нет.

## Запуск

Сначала запустить настоящий FastAPI с SQLite по [инструкции](../../docs/deployment.md). Локальный API слушает `127.0.0.1:8000`; Vite уже проксирует `/api` на этот адрес.

```sh
cd apps/web
npm ci
npm run dev
```

Открыть **http://localhost:5173**. Именно localhost: на этот origin возвращает локальный провайдер, а доступ к заказу сохраняется в `sessionStorage`. `PAYMENT_PROVIDER=mock` у настоящего API означает SQLite + sandbox-платежи, не старый сервер `scripts/mock_api.py`. Режим виден в интерфейсе, деньги в sandbox не списываются.

```sh
npm run build
```

## Что работает

- Два стадиона, восемь матчей с локальными карточками, 33 записи расписания. На главной одновременно три карточки; есть стрелки каталога, поиск и жанры.
- Главный экран с живым 3D-залом, паузой анимации, светлая/тёмная темы и мобильная версия.
- Два зала по 282 места: 9 рядов по 30 кресел и 12 диванов. Выбор в 3D или SVG, клавиатура, обзор/от экрана/сзади/сверху/диваны. Обе схемы используют `Hall.seats`.
- Вид с любого кресла на уровне глаз, осмотр камеры и фигуры зрителей. Контрольные места: ряд 1/место 3, ряд 6/место 12, ряд 10/диван 7.
- Звук трибун через Web Audio: громкость и стереобаланс зависят от расстояния до источников шума; воспроизведение и тест звука включаются пользователем.
- Подбор места по предпочтению: ближе к полю, хороший обзор, ровный звук или ниже цена. Сравнение A/B показывает два реальных ракурса, цену и расстояния; один и тот же кадр позволяет сравнить места без смены сцены.
- Checkout с email, один Idempotency-Key на намерение покупки, сумма от сервера, переход к провайдеру, опрос статуса и восстановление заказа. URL возврата не подтверждает оплату.
- Билет после `paid`, QR публичной проверки, печать, обработка недействительного билета. «Мои билеты» показывает заказы текущей браузерной сессии.
- Loading/error/empty, клавиатура, reduced motion, fallback при отсутствии WebGL.
- `/presentation`: шесть слайдов, клавиатура, заметки, fullscreen и [PDF 16:9](../../docs/artifacts/zal-presentation.pdf).

## API и размещение

[OpenAPI](../../contracts/openapi.json), [пояснения](../../docs/api.md). HTTP-клиент — `src/lib/api.ts`, типы — `src/lib/types.ts`.

По умолчанию API — `/api/v1`. Для другого адреса задать `VITE_API_BASE_URL` до сборки. В production используется единый origin: `/api/*` обслуживает FastAPI, другие маршруты — SPA. При разных origin серверу нужны CORS для GET/POST, Authorization и Idempotency-Key.

`verification_url` ведёт на `/tickets/<token>` без email. Приватный заказ требует Bearer-токен. Доступность обновляется каждые 10 секунд и при возврате фокуса. При 409 checkout закрывается и загружает актуальные места. Один заказ — одно кресло или один диван.

Настоящие API и SQLite уже подключены. Полный браузерный путь проверен через sandbox; настоящая покупка СБП через Platega пока не является подтверждённым результатом этой проверки. [Статус production](../../docs/deployment.md).

## Проверки

`npm run build` проходит. Backend: 35 автоматических проверок с временными SQLite-базами и фейковым провайдером. Через Chromium проверен путь афиша → 3D → checkout → sandbox → QR, обновление страницы и полный рестарт API: один билет остаётся `valid`, место `sold`, QR доступен без приватного токена заказа и без email.

Главная проверена на 390/768/1440 px: три карточки, пагинация 3→3→2, поиск/очистка, темы, превью и возврат фокуса после Escape. Axe: ноль обнаруженных нарушений на проверенных главной в обеих темах, диалоге превью и билете. Текст поверх canvas дополнительно оценён визуально.

Перед живым показом: выбрать произвольное кресло, сменить 2D/3D, проверить три контрольных ракурса, подбор и сравнение A/B, послушать первый/задний ряд и левую/правую сторону в наушниках. Реальную оплату выполняет человек отдельно; серверные проверки не заменяют этот шаг.

Three.js загружается отдельным chunk; сборщик предупреждает о размере более 500 КБ. Без WebGL остаются схема и покупка.

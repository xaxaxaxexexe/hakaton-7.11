# Трибуна — билет с видом на поле

Веб-сервис покупки билетов на спорт. Болельщик выбирает стадион и матч, видит свободные места на схеме трибуны, садится на выбранное место в 3D, смотрит, как оттуда видно поле, и покупает билет. Цена зависит от места.

## Запуск

```bash
python3 server.py
```

Откройте <http://127.0.0.1:8000/>. Другой порт: `PORT=8080 python3 server.py`. Нужен Python 3.9+; сторонние пакеты не требуются. SQLite создаётся в `data/stadium.sqlite3`; билеты и аккаунты сохраняются при перезапуске.

## Что работает

- **Стадионы и матчи.** Три стадиона с разной геометрией, числом секторов и ценами, у каждого своё расписание из шести матчей.
- **Схема трибуны.** Карта стадиона с секторами и схема сектора: поле сверху, ряды 1–9 и ложи в верхнем ряду. Занятые места видны сразу, цена зависит от ряда и сектора.
- **3D-вид с любого места.** Камера стоит в координатах выбранного места. Из первого ряда игроки рядом, а дальняя половина поля сжимается; из центра головы впереди закрывают ближнюю бровку; из ложи поле выглядит как схема тактики. Кнопки «Выше / Ниже / Левее / Правее» пересаживают на ближайшее свободное место, режим «Весь стадион» позволяет выбрать место прямо в 3D.
- **Покупка.** Вход или регистрация, удержание места на 10 минут, тестовая оплата, билет со ссылкой, печатью и экспортом в календарь. Купленное место становится занятым на схеме и появляется в 3D как болельщик.
- **Звук с места.** Шум стадиона синтезируется в браузере через Web Audio. Рядом с фан-сектором громче, на верхней отметке тише, скандирование приходит с реальной стороны.
- **Интеграция.** Прогноз погоды к началу матча из Open-Meteo для матчей в ближайшие 14 дней. Покупка от этого сервиса не зависит: при сбое показывается короткое сообщение.
- **Свои идеи.** Подбор места («Лучший обзор», «Ближе к полю», «Выгоднее») и карта ракурса с оценкой обзора.
- **Телефон.** Адаптивный интерфейс и установка как PWA (нужен HTTPS).

Тестовые карты: **4242 4242 4242 4242** — успех, **4000 0000 0000 0002** — отклонение. Настоящие карты вводить не нужно, деньги не списываются.

**Стадионы, клубы и матчи вымышлены, билеты демонстрационные.** Для реальной продажи нужны данные организаторов, платёжный провайдер и подтверждение брони.

## Как добавить стадион

Отредактируйте `stadiums.json` и перезапустите сервер. Код менять не нужно: стадион описывается размерами сектора, ценами и списком секторов (`side` — сторона поля, `offset` — смещение вдоль неё, `price_factor` — множитель цены, `fan` — фан-сектор). Матчи добавляются в тот же файл. Уже выданные билеты сохраняют оплаченную цену.

## Устройство

- `server.py` — HTTP API и статика без зависимостей, SQLite, оплата, аккаунты. Уникальный индекс `(match_id, seat_id)` и транзакции не дают продать место дважды.
- `seat_position()` в `server.py` — единственный источник координат мест. Схема и 3D читают одни и те же данные, поэтому не расходятся.
- `web/stadium3d.js` — сцена на Three.js: поле, чаша трибун, места, болельщики, игроки, камера и звук.
- `web/app.js` — страницы, схема, подбор места, покупка.

API: `/api/catalog`, `/api/matches/<id>`, `/api/matches/<id>/weather`, `/api/auth/*`, `/api/payments/*`, `/api/me/tickets`, `/api/tickets/<token>`, `/api/health`.

Three.js включён локально под MIT.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Откройте матч, выберите сектор и место, нажмите «Сесть и посмотреть». Сравните ряд 1, ряд 6 и ложу, включите звук, зарегистрируйтесь и оплатите картой 4242. После этого место занято, а билет доступен в «Моих билетах» и после нового входа.

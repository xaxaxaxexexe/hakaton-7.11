# Билет с видом на поле (команда D4C)

Веб-сервис покупки билетов на матч: стадион → матч → схема сектора → 3D-вид на поле с места (Three.js) → покупка. Данные в MySQL. Цены 700 / 1200 / 3500 ₽ (ряды 1–3, ряды 4–9, ложи), в 3D — поле 105 × 68 м с трибунами, болельщиками и прожекторами. Стадионы и клубы вымышленные.

## Запуск
1. Установите MySQL 8 (или MariaDB 10.5+) и Node.js 19+ (в Node 18 запускайте с `--experimental-global-webcrypto`).
2. `cp .env.example .env` и впишите `DB_USER` / `DB_PASSWORD`.
3. `npm install`
4. `npm run seed` — создаст БД `arena3d`, таблицы и демо-данные (повторный запуск пересоздаёт всё).
5. `npm start` → http://localhost:3000 (`/?debug` — кнопки трёх контрольных мест в 3D).

## Структура
- `db/schema.sql` — таблицы. `db/seed.js` — стадионы, сектора, тарифы и генератор мест и расписания (матчи всегда в будущем).
- `server/` — Express API; покупка в транзакции, цена берётся из БД, `UNIQUE(session_id, seat_id)` защищает от двойной продажи.
- `public/js/` — `main.js` (сценарий), `seatmap.js` (схема сектора), `view3d.js` (3D), `sound.js` (шум трибун с места), `api.js`.
- Схема и 3D используют одни и те же координаты x/y/z мест из БД. Новый сектор = запись в `HALLS` + `npm run seed`, интерфейс менять не нужно.

## Демо (2–3 мин)
Стадион → матч → цены 700/1200/3500 ₽ → «Ряд 1, место 3» → «Ряд 6, место 12» → «Ряд 10, ложа 7» (смотреть 3D, возвращаться к схеме) → купить → место занято; после обновления страницы билет сохранён по ссылке.

## Страницы
- `#/` — главная: слайдер матчей, вкладки «Матчи» / «Скоро», фильтр по турнирам, карточки матчей с ценой «от».
- `#/match/ID` — матч: описание, расписание по стадионам и дням → выбор места.
- `#/soon` — скоро в продаже, `#/reviews` — обзоры, `#/stadiums` — стадион → матч.
- `#/tickets`, `#/account`, `#/history` — билеты, кабинет, история.
- Видео обзора: впишите в поле `trailer_url` матча ссылку `https://www.youtube.com/embed/ID` или на `.mp4`, иначе показывается заставка.

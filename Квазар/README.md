# МатчВид — билет с видом на поле
Запуск: python3 server.py, затем http://localhost:8000 (нужен Python 3.8+). БД SQLite matchvid.db создаётся и заполняется при первом запуске: три стадиона, матчи, цены по рядам (ряды 1–3, 4–9, ложи).
Выбор стадиона и матча, схема трибуны, 3D-вид на поле с любого места (Three.js), звук стадиона с места (Web Audio), покупка и возврат билета. Стадионы, клубы и матчи вымышленные, оплата демонстрационная.
Таблицы: стадионы, цены по рядам, матчи, расписание, пользователи, способы оплаты, билеты, места в билете (UNIQUE по матчу и месту), токены.

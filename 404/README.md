# Sphera Arena — билет с видом на поле

Сервис покупки билетов на матч: выбрать матч и сектор, сесть на любое место трибуны в 3D, посмотреть на поле с этой точки, послушать стадион и купить билет. Цена зависит от сектора и ряда: ряды 1–3, ряды 4–9 и VIP-ложи на верхнем ярусе.

3D-сцена: поле 105 × 68 м с разметкой, ворота, трибуны с болельщиками, прожекторы, рекламные щиты. Стадион, клубы и матчи вымышленные, оплата тестовая.

## Запуск

```bash
npm install
API_URL=https://sphera-3d-grozny.vercel.app npm run dev   # сайт на :5173 с живым API
npm run build                                             # сборка в dist/
```

Без `API_URL` dev-сервер проксирует `/api` на `http://localhost:8000`. На Vercel `/api/*` уходит в Supabase Edge Function (`vercel.json`), остальное отдаёт `index.html`.

## Страницы

| Путь | Страница |
|---|---|
| `/` | Афиша матчей на неделю, фильтр «Все / Стандартные / VIP» |
| `/match/:id` | Матч и места по секторам |
| `/sectors` | Все сектора стадиона: стандартные и VIP |
| `/sector/:id` | Сектор в 3D: сесть на любое место, проверить звук |
| `/seats/:id` | Выбор до 8 мест, вид и звук с места, бронь |
| `/checkout/:id` | Бронь на 10 минут, оплата или отмена |
| `/pay/:id` | Тестовый платёжный шлюз Sandbox Pay |
| `/order/:id` | Оплаченные билеты с QR-кодами |
| `/tickets` | Мои билеты (заказы этого браузера) |

## Что внутри

```
index.html          шапка, навигация, кнопка звука, canvas для 3D
vite.config.js      сборка; локально /api проксируется
vercel.json         /api/* → Supabase Edge Function, остальное → index.html
src/
  main.js           роутер (history API) и шапка
  stadium.js        матчи, сектора, клубы и цены для интерфейса
  lib.js            запросы к API, даты и цены, карточки матчей, «мои заказы» в localStorage
  pages/catalog.js  афиша и страница матча
  pages/halls.js    список секторов
  pages/scene.js    3D-страницы сектора и выбора мест
  pages/orders.js   бронь с таймером, тестовая оплата, билеты с QR
  scene/stage.js    three.js: камера, пересадка на место, свет, bloom
  scene/hall.js     сектор трибуны, поле, стадион вокруг
  audio/engine.js   Web Audio: шум трибун, проверка звука с места
  ornament.js       орнамент и значки
  style.css, app.css
```

## Бронь и оплата

Места держатся 10 минут, заказ получает токен (HMAC от id). Оплата идёт через тестовый шлюз Sandbox Pay: шлюз подписывает уведомление, сервер проверяет подпись и сумму и выдаёт билеты. Если оплата пришла после истечения брони, билеты не выдаются.

Для настоящего запуска: подключить эквайринг (ЮKassa, CloudPayments), отправку билетов на e-mail и реальные схемы секторов из билетной системы стадиона.

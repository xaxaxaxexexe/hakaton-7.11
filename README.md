# Хакатон 7.11 — «Билет с видом на поле»

Решения команд по кейсу «Билет с видом на поле»: веб-сервис, где болельщик выбирает стадион и матч, видит свободные места на схеме трибуны, садится на место в 3D, смотрит, как оттуда видно поле, и покупает билет. Цена зависит от места: например, 700 ₽ за ряды 1–3, 1200 ₽ за ряды 4–9 и 3500 ₽ за ложу.

# Арена 3D — билет с видом на поле

Сервис покупки билетов на матч со свободной 3D-прогулкой по стадиону: выбрать матч и сектор, пройти через подтрибунное помещение и фуд-корт к своему сектору, сесть на любое место, посмотреть на поле и оформить заказ.

## Запуск

Через Docker: `docker compose up --build -d`, затем http://localhost:4173. База SQLite лежит в томе `arena_data`: аккаунты, сессии входа и заказы сохраняются после перезапуска. Остановить: `docker compose down`.

Без Docker: Node.js 24+, `npm run dev`, затем http://127.0.0.1:4173. Ставить зависимости не нужно.

Проверка: `npm test` (движение, геометрия трибуны, звук, корзина, регистрация, оплата, выдача файлов).

## Сценарий

1. Выбрать матч и сектор в расписании. Откроется подтрибунное помещение у касс и фуд-корта.
2. Открыть фуд-корт клавишей E или кнопкой, собрать заказ и увидеть сумму.
3. Пройти по коридору к своему сектору: нужная дверь подсвечена на плане.
4. Выйти на трибуну, пройти между рядами, сесть на место и осмотреться. Поле лежит ниже первого ряда, напротив — трибуна с табло.
5. «Начать → к оплате» открывает состав заказа с выбранным матчем и местом.
6. Пройти демонстрационную оплату без списания денег.

Управление: WASD или стрелки — ходьба, Shift — быстрее, мышь с зажатой кнопкой — осмотр, E — действие / сесть / встать, Esc — отпустить мышь. На телефоне — экранные стрелки и свайп по сцене.

## Устройство

- `schedule-data.js` — расписание: матчи, сектора, цены. Карточки матчей в `assets/match-*.svg`.
- `hall-model.js` — геометрия сектора: 8 рядов по 14 мест, подъём рядов, положение поля; общая для схемы, камеры и столкновений.
- `hall-scene.js` — 3D-сцена: места, ступени, поле 105 × 68 м, ворота, игроки, трибуны с болельщиками, прожекторы, табло.
- `lobby.js` — подтрибунное помещение: кассы, фуд-корт, двери секторов.
- `walk.js` — прогулка, посадка на место, план, подсказки.
- `stadium-audio.js` — пространственный звук.
- `commerce.js`, `server.cjs` — корзина, заказ, оплата (демо или тестовый режим ЮKassa), аккаунты.

Регистрация: почта и пароль от 10 символов, пароль хранится в виде хеша, вход запоминается в защищённой cookie.

Стадион, клубы и матчи вымышленные, оплата демонстрационная.
